# Grok Bot Switch v0.2.0-beta.1

Windows x64 便携预览版，非 xAI / X 官方项目。

## 使用

1. 下载 ZIP，完整解压，双击 `GrokBotSwitch.exe`。不需要安装 Python 或 Node；Windows 需要 WebView2 Runtime。
2. 本机需已安装并登录 Grok Bot。首次连接前先退出 Grok Bot，再点击「连接 Grok Bot」；程序会备份安装文件并重新打开应用。
3. 添加兼容供应商的 HTTPS URL、API key 和模型，选择协议，点击「使用」。可切回官方或上一通道，不绑定特定供应商。

已有验收版用户请保留原有数据目录并沿用现有快捷方式，不要在另一数据目录重复接入已适配的 Grok Bot 安装。

## 已验证

- Windows Grok Bot 0.28.0 的本机发现、备份、适配和原版恢复。
- 官方 → 自定义 OpenAI Chat API → 官方的真实切换。
- 普通 Bot 聊天返回 `GROK_BOT_SWITCH_EXTERNAL_OK`，五条外部请求与供应商回执一致。
- 切换等待原生重启回执与健康状态，不强制中断正在运行的任务；外部模式失败不自动回落官方推理。

## 预览版限制

- 仅适配固定的 Windows 0.28.0 安装包和已知云端版本；未知版本拒绝修改。
- Responses、Anthropic Messages 已有本地测试，但未完成同等实机供应商验收。供应商 OAuth 未开放，未提供 macOS/Linux 桌面包。
- 切换影响当前云端的所有 Bot；供应商地址和密钥会同步到该云端的私有目录。现有原生账号凭据不会被导出。
- 外部模式不支持原生语音转写。原生用量界面的百分比不足以证明精确零扣费。
- 这是未签名的便携测试包，不含安装器。不要关闭 Windows 安全防护；原生更新后可能需要重新验证兼容性。
- 状态不确定时不要重复切换或删除备份；并非所有主机崩溃都能自动恢复。

附件 `SHA256SUMS.txt` 可用于核对下载完整性。
