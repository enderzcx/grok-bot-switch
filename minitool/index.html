Grok Bot Switch

让 Grok Bot 用你自己的模型

一段提示词装好，之后在聊天框里一行字切换。支持 OpenAI / Claude 兼容接口，也能直接用 ChatGPT 订阅。

第一步：选一种安装方式

Grok Bot 装好后在它的云端电脑上打开一个配置面板，你在 Grok Bot 的云端桌面里自己填供应商、测试、切换，也可以在面板里用 ChatGPT 登录。API key 不经过聊天记录。

第三步：等 Grok Bot 回复

  1. Grok Bot 下载工具、给它的云端主程序打补丁、申请一次重启。这一次重启在它回复完后由 Grok 自带的机制执行，几秒钟。
  2. 面板模式：Bot 会说"面板已打开"，你在 Grok Bot 的云端桌面里操作面板；直接配置模式：Bot 先向你的接口发一条测试请求，通过后立刻切换。
  3. 新开一条消息试试。发 /gs status 可以确认当前走的是哪个模型。

装好之后，在聊天框里切

这些消息在云端主程序里直接处理，不发给任何模型、不花 token、任何平台都一样。

/gs use myapi切到已保存的供应商，下一条消息生效
/gs official切回官方 Grok，配置保留
/gs status看当前走哪里、保存了哪些供应商

再加一个供应商

面板模式：对 Grok Bot 说"打开 grok-switch 面板"，在面板里添加。直接配置模式：回到"安装"页换个名字和参数，再生成一段提示词发给它。已保存的供应商都会保留，随时 /gs use 切换。

面板里能做什么

  • 添加、修改、删除供应商；保存时真发一条测试请求，地址、key、模型任何一个不对当场报出来
  • 一键切换、切回官方、卸载补丁
  • 用 ChatGPT 登录代替 API key
  • 看每个供应商累计用了多少次、多少 token，以及最近请求的状态和错误原因

用 ChatGPT 订阅，不用 API key

用的是你 ChatGPT Plus / Pro 的额度。登录在你自己的手机或电脑上完成，云端只保存登录凭据，过期自动刷新。

  1. 在面板里点"登录 ChatGPT"（云端没装 Codex CLI 的话先点"安装 Codex CLI"）。
  2. 面板显示一个网址和一次性验证码。在你自己的浏览器里打开网址、输入验证码、登录 ChatGPT。
  3. 回到面板，登录成功后会自动保存一个叫 chatgpt 的供应商，点"使用"即可。

请先知道这一点

这是让 Codex 的后端为非 Codex 程序提供服务，在 OpenAI 的条款上属于擦边行为，账号有被限制的可能。是否使用请自行权衡。Claude 的账号登录不支持，Anthropic 接口请用 API key。

它是怎么工作的？会改我电脑上的 Grok Bot 吗？

不改你本机的任何东西。Grok Bot 的推理请求不是从你的 Mac / Windows 发出的，而是从它的云端 Linux 电脑里的主程序发出的。工具在云端主程序创建推理会话的地方接了一段代码：没选供应商就照旧走官方 Grok；选了就直接从云端请求你的接口，请求、流式回复、工具调用、推理内容都按协议转换。

为什么安装时要重启一次主程序？以后每次切换都要重启吗？

主程序是一个正在运行的进程，代码在启动时已经读进内存，改磁盘文件不会影响它，只有重启一次才带着补丁起来。这一次在安装时就申请了，由 Grok 自带的机制在没有 Bot 忙碌时执行。之后切换只是改配置文件，主程序每次新会话读一遍，不再重启。

Grok Bot 升级了怎么办？

升级会覆盖主程序，补丁随之丢失，请求会自动回到官方 Grok。面板和 /gs status 会提示；再点一次"使用"或把安装提示词再发一次即可重新打补丁。工具不依赖 Grok Bot 的具体版本号，只认主程序里一个函数名。

API key 会被谁看到？

用面板模式配置，key 只写进云端一个仅当前用户可读的文件，不经过聊天记录。用直接配置模式并把 key 写进提示词，它会出现在你和 Grok Bot 的对话历史里。面板和请求日志都不回显 key。

接口报错、余额不足了会怎样？

对话直接显示供应商返回的错误原文（比如 401 key 无效、429 限流），并写进请求日志。不会悄悄回落到官方 Grok 计费。

已有的旧对话能直接切吗？

能。官方 Grok 产生的历史里有外部接口无法表达的内容（脱敏推理、带签名的推理、工具返回的截图、文件附件），会按规则降级而不是报错：脱敏推理丢弃，工具截图改用图片消息携带，附件替换成一行占位文字。

哪些功能不走我的供应商？

切换影响同一云端上的所有 Bot 的对话推理。语音转写、对话标题生成等非推理功能仍走官方。

怎么彻底卸载？

面板里点"卸载补丁"，或对 Grok Bot 说执行 node /workspace/grok-switch/grok-switch.cjs restore。主程序会逐字节恢复成原文件并重启一次。
